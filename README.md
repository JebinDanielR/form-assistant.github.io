# Gov Form Assistant

AI-powered government form filling assistant.
Upload your Aadhaar, passbook, and land record —
the AI reads them and fills the form automatically.

## Stack
- Frontend: React + Vite
- Backend: FastAPI + Python
- Database: PostgreSQL
- Vector DB: Qdrant
- LLM: Qwen3-VL via Ollama (local)
